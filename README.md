# SQL Projects

A collection of SQL exercises, projects, datasets, and reference solutions to practice and demonstrate SQL skills across different relational database systems (SQLite, PostgreSQL, MySQL). Organized by difficulty and topic so you can learn step-by-step or use these exercises for teaching and interviews.

## About
This repository is intended for learning, practicing, and demonstrating SQL. Each exercise includes:
- a problem description (Markdown),
- one or more SQL files for the expected queries,
